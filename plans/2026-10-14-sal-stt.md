# sal-stt: one speech-to-text package for every app

Status: active (2026-10-14). Lead: the sal-agent session. Repo: `G:\code\sal-stt` (GitHub `dested/sal-stt`, private).

## Why

Sal needs speech-to-text in many apps: web, Electron, Expo (iPhone, iPad, Android), and Iris's always-on ears. Today
Iris runs Whisper large-v3-turbo through whisper.cpp 1.9.5 (current release, but a late-2024 model at ~7.8% English
WER). Newer models do better: NVIDIA Parakeet TDT 0.6B v3 (~6.3%, much faster), Moonshine v2 (small, streaming,
runs everywhere), Apple SpeechAnalyzer (built into iOS 26+, free). He wants one solution across the board.

## Sal's decisions (2026-10-14)

- **Iris switches to Parakeet** now. No bake-off first. A regression check on his saved audio still gates the flip.
- **One shared package**, `dested/sal-stt`: one TypeScript API, a backend per platform, installed from GitHub
  (`github:dested/sal-stt`) like expo-wsl-ios. Iris is its first user.
- **Web: both, browser first.** On-device in the browser by default; a server fallback (Drydock) for weak devices.
- **iPhone / iPad: the higher scorer.** Apple SpeechAnalyzer vs Parakeet (CoreML), scored on his audio; ship the winner.

## Shape

One API everywhere:

```ts
const stt = await createStt({ ...platformOptions })
const { text } = await stt.transcribe(pcm16, { sampleRate: 16000, hotwords: ["Iris", "Frozen Ropes"] })
await stt.close()
```

Batch first (Iris and most apps cut speech with VAD). A streaming API (`stt.stream()` → partial / final events) comes
with the browser and Expo backends, where live text matters.

| Backend | Platforms | Engine | Model |
| --- | --- | --- | --- |
| `sal-stt/node` | Bun, Node, Electron main, servers | sherpa-onnx (N-API addon, or its prebuilt binary as a sidecar) | Parakeet TDT 0.6B v3 int8 |
| `sal-stt/browser` | web, Electron renderer | ONNX Runtime Web (WebGPU, WASM fallback) | Moonshine v2 (small download), Parakeet fp16 opt-in on strong GPUs |
| `sal-stt/server` | web fallback | the node backend behind a WebSocket endpoint any app can mount | Parakeet (CPU on Drydock) |
| `sal-stt/expo` iOS | iPhone, iPad | Apple SpeechAnalyzer or Parakeet CoreML (FluidAudio), the higher scorer | |
| `sal-stt/expo` Android | Android | sherpa-onnx (Kotlin) | Parakeet v3 int8 or Moonshine |

Models download on first use into an app-chosen folder (never committed); `sal-stt fetch <model> <dir>` does it ahead.

## Known risks

- Whisper took a text prompt to steer spelling (project names, "Iris"). Parakeet doesn't; sherpa-onnx hotwords
  (contextual biasing) may cover it for transducer models. If not, the Listener prompt already maps mishearings.
- sherpa-onnx's npm addon may be CPU-only. Parakeet on a 32-thread CPU should still be fast for 2–10 s segments;
  measure before reaching for a CUDA build.
- Bun + N-API addons: verify; a sidecar binary is the fallback.
